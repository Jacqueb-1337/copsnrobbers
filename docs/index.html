Cops N Robbers Revival

A preservation project for the original Cops N Robbers Android game. The project restores multiplayer, replaces the discontinued online backend, adds a reusable mod system, and keeps the original client usable on newer Android devices.

Download Source Server project Project V7

What was revived

The original game depended on multiplayer services that are no longer available. The revival work reverse engineered the client's networking behavior, redirected it to a community-controlled backend, and rebuilt enough of the original flow for room discovery, hosting, joining, and live matches.

Current project pieces

Replacement multiplayer server

The custom Node.js backend handles the services the revived client needs, including room listing, connection redirection, hosting, joining, and in-room traffic. The server work is also documented separately in the CNR Revived Web project.

Mod loader

The patched client can load C# mod DLLs at runtime. That lets the project ship fixes and features without rebuilding the entire APK every time. Existing work includes server redirection, an in-game HUD editor, settings tools, and recording support.

Original gameplay preserved

The goal is to preserve the original game behavior and client rather than recreate Cops N Robbers from scratch. The replacement pieces exist around the original game so the project remains useful as preservation and reverse-engineering work.

Modern Android compatibility

The original Cops N Robbers build is a 32-bit ARMv7 Android application. Many newer 64-bit-only phones cannot launch it natively.

Project V7 provides the compatibility layer used by the revival on supported modern devices. Project V7 is a separate open-source Android compatibility project for running supported legacy 32-bit apps on 64-bit-only Android hardware.
