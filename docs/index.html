CNR REVIVAL

Project Info

Cops N Robbers Revival is a preservation project for the original Android game. The project keeps the original client and gameplay intact while replacing the pieces that stopped working over time.

Original clientThe original Unity game remains the base. This is not a remake.
Online revivalRoom discovery, hosting, joining, and live matches run against a replacement backend.
Mod supportA reusable C# mod loader allows fixes and features without rebuilding the full game for every change.
Modern AndroidProject V7 supplies the compatibility path used on supported 64-bit-only Android devices.

Multiplayer Restored

The original online services are no longer required. The revived client can connect to the custom Node.js master and game servers, discover rooms, create matches, join other players, and complete the original Photon-era multiplayer flow.

Mods

The revived build includes a runtime C# mod loader. Existing modules cover server redirection, the mod manager, settings and HUD customization, recording, freecam tools, skins, and other compatibility work.

Several of the UI elements on this page come directly from the original game's Unity texture atlases. The visual layout intentionally follows the game's main-menu style.

Project V7

The original Cops N Robbers build is a 32-bit ARMv7 Android application. Newer 64-bit-only phones may not be able to launch it natively.

Project V7 provides the compatibility layer used by the revival on supported modern devices. Project V7 is a separate open-source Android compatibility project for legacy 32-bit apps and games.
