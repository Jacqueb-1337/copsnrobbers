Android game preservation and revival

Cops N Robbers Revival

A community project preserving the classic Cops N Robbers Android game by restoring multiplayer, replacing the discontinued online backend, adding a reusable mod system, and keeping the game playable on modern Android hardware.

What the CNR Revival project does

The project began as a reverse-engineering effort to understand how the original Cops N Robbers Android client communicated with its multiplayer services. That work grew into a complete revival stack that can redirect the original game to a community-controlled server, restore room discovery and joining, and support live multiplayer matches again.

Restored multiplayer

A custom Node.js server recreates the master and game-server behavior the original client expects, including authentication, room listing, hosting, joining and in-room traffic.

Photon compatibility

The original networking path was reverse engineered and adapted so the game can communicate with the replacement backend using the protocol behavior it already understands.

Mod loader

The revived build supports loadable C# mods, allowing features and fixes to evolve without rebuilding the entire game for every change.

Game improvements

Existing revival work includes an in-game settings and HUD editor, recording support, server redirection and compatibility fixes for the original Unity-era Android code.

Modern Android and 64-bit-only phones

The original game is a 32-bit ARMv7 Android title. Many newer phones are 64-bit-only and cannot launch the original binary directly.

Project V7 provides the modern Android compatibility layer used to keep Cops N Robbers running on supported 64-bit-only devices. Project V7 is a separate open-source Android compatibility project that wraps and patches supported legacy 32-bit apps instead of requiring a full old-Android virtual machine.

Learn about Project V7 or view the Project V7 source on GitHub.

How the revival fits together

Original game client

The preserved Cops N Robbers client remains the basis of the project. Compatibility and mod hooks are added around it rather than replacing the gameplay with a remake.

CNR mod system

Runtime C# modules provide server redirection, interface tools and optional features. The loader is designed so additional mods can be added independently.

CNR Revived server

The companion Node.js backend replaces the unavailable original multiplayer services and provides the server-side room and match infrastructure.

Project V7

For supported modern devices, Project V7 handles the 32-bit-to-64-bit compatibility layer required to launch the legacy ARMv7 game.

Project status

The core revival milestones have been completed. Multiplayer has been demonstrated end to end against the custom server, the mod loader is functional, and public builds are distributed through the GitHub repository.

The project remains useful as a preservation, reverse-engineering and Android compatibility effort. New fixes, mods and compatibility work can continue without changing the purpose of the original game.
