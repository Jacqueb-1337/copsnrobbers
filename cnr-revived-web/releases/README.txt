CNR Revival — Installation Instructions
========================================

CONTENTS OF THIS ZIP
---------------------
  CopsNRobbers-v2.0.1.apk   Patched game APK with mod loader built in
  CNRModManager.dll          Mod manager — browse and install mods in-game
  README.txt                 This file


INSTALLATION
------------

1. INSTALL THE APK
   - Uninstall the original Cops n Robbers if you have it installed.
   - Transfer CopsNRobbers-v2.0.1.apk to your Android device.
   - Open it and tap Install (you may need to allow "Install from unknown sources"
     in your device settings under Security or Apps).

2. PLACE THE MOD DLL
   - Connect your device via USB (or use a file manager app).
   - Navigate to:  /sdcard/CNRMods/
     (create the folder if it does not exist)
   - Copy CNRModManager.dll into that folder.

3. LAUNCH THE GAME
   - Open Cops n Robbers.
   - The Mod Manager will appear automatically.
   - Go to the Browse tab — CNRMod will be listed as a required update.
     Tap Install / Update to download it. The game will reload your mods.

4. PLAY
   - Tap Multiplayer to connect to the community server.
   - Register an account on first launch (your progress is saved server-side).


TROUBLESHOOTING
---------------
  - If mods don't load, double-check the DLL is in /sdcard/CNRMods/ (not a subfolder).
  - If you see "REQUIRED" in red next to a mod, tap it to update — outdated mods
    are blocked from connecting to the server.
  - For help, visit: https://play.jacqueb.me
