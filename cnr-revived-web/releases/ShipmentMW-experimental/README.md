# Shipment MW (CODM, Experimental) for CNR

This is a distinct, native-CODM-source DLC map. The pre-existing Minecraft-made Shipment DLC is not changed.

Map ID: shipmentmw

Map: https://play.jacqueb.me/economy/uploads/maps/shipmentmw.json

Test CNRMod DLL (version 4.2.55): https://play.jacqueb.me/mods/CNRMod/CNRMod-4.2.55-ShipmentMW-experimental.dll

Stable CNRMod latest version stays 4.2.53. The experimental build is manual-only; it does not trigger auto-updates. To test it, back up the current /sdcard/CNRMods/CNRMod.dll and install the downloaded test DLL using the CNRMod.dll filename, then restart the game.

Contains 261,913 source visual triangles, 88 color tiles, 42 native collision meshes and 31 original TDM spawn coordinates. Full native material fidelity, baked lighting, team assignment, runtime performance, collider physics and game playability are NOT verified. Use for testing only.
